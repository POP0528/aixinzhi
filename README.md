# 欸!愛新知

AI 新知看板：依看板整理好的 AI 新聞與模型發布、每日／每週報告、語音播報，每篇文章都有重點整理，還能直接提問。

> 這裡只提供 Windows 版的**安裝檔**。新聞的收集與整理在「分享者」的電腦上完成——安裝後需要分享者給你的**位址**與**邀請碼**才能使用。

## 下載

到右側的 **[Releases](../../releases/latest)**，下載最新版的 `AiXinZhi-Setup-x.y.z.exe`。

- 系統需求：Windows 10／11（64 位元）
- 不需要系統管理員權限，只安裝在你自己的帳號底下（`%LOCALAPPDATA%\Programs\AiXinZhi`）

## 安裝

1. 執行下載的 `AiXinZhi-Setup-x.y.z.exe`。
2. 如果出現「**Windows 已保護您的電腦**」：這是因為安裝檔還沒有付費的程式碼簽章，按「**其他資訊**」→「**仍要執行**」即可。（擔心的話，可以先用下方的方式核對檔案。）
3. 安裝時可選擇建立桌面捷徑、開機時在背景執行（才收得到新消息通知）。
4. 打開後輸入分享者給你的**位址**與**邀請碼**，替這台電腦取個名字，按「連線」。

之後有新版本時，APP 會直接提示更新，不必再回來這裡下載。

## 核對檔案（選用）

每個版本的說明裡都附有安裝檔的 SHA-256。在 PowerShell 執行：

```powershell
Get-FileHash .\AiXinZhi-Setup-x.y.z.exe -Algorithm SHA256
```

結果和版本說明裡的一樣，就表示檔案完整、沒有被改過。

## 你的資料

- 你的訂閱、收藏、閱讀與提問紀錄存在**分享者的電腦**，分享者看得到；只在你和分享者的電腦之間以 https 加密傳送，不會給其他人。
- 回答與整理都由分享者電腦上的本地模型完成，不使用雲端 AI；APP 沒有使用統計、廣告或追蹤。
- 想刪除資料：APP 左側「連線設定」→「中斷連線」，勾選「同時刪除我在分享者電腦上的資料」。
- 完整說明在 APP 左側「關於與隱私」。

## 解除安裝

Windows「設定」→「應用程式」→ 找到「欸!愛新知」→ 解除安裝。
