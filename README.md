# 欸!愛新知

AI 新知看板：依看板整理好的 AI 新聞與模型發布、每日／每週報告、語音播報，每篇文章都有重點整理，還能直接提問。

> 這裡提供 Windows 與 Android 的**安裝檔**。新聞的收集與整理在「分享者」的電腦上完成——安裝後需要分享者給你的**位址**與**加入碼**才能使用。（iPhone／iPad 目前沒有。）

## 下載

到右側的 **[Releases](../../releases/latest)**，在最新版下方的 Assets 選一個：

| 你的裝置 | 下載 |
|---|---|
| Windows 10／11（64 位元） | `AiXinZhi-Setup-x.y.z.exe` |
| Android 手機（7.0 以上；幾乎所有手機選這個） | `AiXinZhi-x.y.z-arm64-v8a.apk` |
| 很舊的 Android 手機（上面那個裝不起來時） | `AiXinZhi-x.y.z-armeabi-v7a.apk` |

## 安裝：Windows

1. 執行下載的 `AiXinZhi-Setup-x.y.z.exe`。不需要系統管理員權限，只安裝在你自己的帳號底下（`%LOCALAPPDATA%\Programs\AiXinZhi`）。
2. 如果出現「**Windows 已保護您的電腦**」：這是因為安裝檔還沒有付費的程式碼簽章，按「**其他資訊**」→「**仍要執行**」即可。（擔心的話，可以先用下方的方式核對檔案。）
3. 安裝時可選擇建立桌面捷徑、開機時在背景執行（才收得到新消息通知）。
4. 打開後按「**貼上邀請訊息**」（先複製分享者傳給你的整段訊息），位址與加入碼會自動填好；再填你的稱呼，按「連線」。

## 安裝：Android

1. 用手機的瀏覽器打開這一頁，下載 `.apk` 檔，下載完點開它。
2. 第一次會問是否允許這個瀏覽器「**安裝不明應用程式**」：按「設定」打開允許，再回來按「安裝」。
3. 如果 Google Play 安全防護提示「不明的應用程式」：這是因為 APP 沒有在 Play 商店上架，按「**更多詳細資料**」→「**仍要安裝**」。
4. 打開後按「**貼上邀請訊息**」（先複製分享者傳給你的整段訊息），位址與加入碼會自動填好；再填你的稱呼，按「連線」。允許通知，才收得到新消息提醒。

第一次連上時會自動打開「使用指南」，教你各個功能在哪裡；之後也可以在 APP 的「使用指南」（電腦在左側欄、手機在「更多」裡）再看一次。

之後有新版本時，APP 會直接提示更新（Android 第一次更新時會再問一次是否允許「欸!愛新知」安裝更新），不必再回來這裡下載。

## 核對檔案（選用）

每個版本的說明裡都附有每個檔案的 SHA-256。在 Windows 的 PowerShell 執行：

```powershell
Get-FileHash .\AiXinZhi-Setup-x.y.z.exe -Algorithm SHA256
```

結果和版本說明裡的一樣，就表示檔案完整、沒有被改過。

## 你的資料

- 你的訂閱、收藏、閱讀與提問紀錄存在**分享者的電腦**，分享者看得到；只在你和分享者的電腦之間以 https 加密傳送，不會給其他人。
- 回答與整理都由分享者電腦上的本地模型完成，不使用雲端 AI；APP 沒有使用統計、廣告或追蹤。
- 想刪除資料：APP 的「連線設定」（電腦在左側、手機在「更多」裡）→「中斷連線」，勾選「同時刪除我在分享者電腦上的資料」。
- 完整說明在 APP 的「關於與隱私」。

## 解除安裝

- Windows：「設定」→「應用程式」→ 找到「欸!愛新知」→ 解除安裝。
- Android：長按「欸!愛新知」圖示 →「解除安裝」。

## 授權

APP 使用的字型、圖示與插圖授權，Windows 版隨安裝檔附在安裝資料夾的 `licenses` 內；兩個版本都可以在 APP「關於與隱私」→「開放原始碼授權」查看。
